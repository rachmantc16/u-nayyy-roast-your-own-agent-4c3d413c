A tiny deterministic Node program that writes one line roasting the AI agent its own team built — the one that watched 37 mint spots sit open, fired the wrong function selector, blamed a sellout, then apologized at length. The single line (under 200 characters, no trailing newline) is written to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
